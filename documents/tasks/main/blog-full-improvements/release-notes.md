# 블로그 탐색 및 성능 개선 릴리스 노트

## 주요 변경

- 홈에서 대표 프로젝트와 최근 글을 명확히 구분하고 각각 전체 목록으로 이동할 수 있습니다.
- 소개 페이지에서 프로필과 포트폴리오를 함께 확인할 수 있습니다.
- 카테고리 페이지가 서버 페이지네이션을 사용해 훨씬 가벼워졌습니다.
- 시리즈 칩이 공유 가능한 시리즈 페이지 링크로 동작합니다.
- 검색 자동완성과 카테고리·시리즈·연도 필터를 함께 사용할 수 있습니다.
- 태그 허브는 여러 글을 실제로 연결하는 태그만 보여줍니다.
- 공유 전용 이미지와 정확한 작성자 구조화 데이터를 적용했습니다.
- 댓글은 읽는 위치에 도달할 때 불러와 초기 로딩을 줄입니다.

## 측정 결과

| 항목 | 변경 전 | 변경 후 |

| 로그 카테고리 첫 페이지 | 596KB | 약 24KB |
| 공부 카테고리 첫 페이지 | 491KB | 약 29KB |
| 태그 허브 | 177KB | 약 39KB |
| 빌드 결과물 | 88MB | 약 75MB |

## 운영 변경

- pull request에서도 Hugo 빌드와 정적 검증을 실행합니다.
- 배포는 기존처럼 main push 또는 수동 실행에서만 수행합니다.
- 검색 인덱스와 주요 페이지에 크기 예산을 적용했습니다.

## 호환성

- 기존 게시글 URL은 변경하지 않았습니다.
- 기존 태그 URL은 유지하지만 검색엔진 색인 대상에서는 제외됩니다.
- 카테고리의 JavaScript 필터 버튼은 시리즈 페이지 링크로 대체됩니다.
